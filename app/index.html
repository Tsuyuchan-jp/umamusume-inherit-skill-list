継承白因子リスト

任意コースの有効スキル（白∩共通）から、本育成で取れる分を除いた先頭25件を、ウマ娘DB貼り付け用にコピーします。

育成ウマ娘
サポートカード（優先40種）

先頭25件

    コピーしたテキストを レンタル因子貼り付け に貼ってください。検索ボタンは押しません。

    使い方

    U-tools の有効スキルを、白スキルかつ共通スキルに絞ったリストから、本育成（ウマ娘・サポカ・シナリオ自動）で取れるスキルを除きます。

    • サポカは優先40種のみ。絞り込みはタイプだけです
    • イベントは全選択肢を「取れる」とみなします（UIなし）
    • シナリオは自動付与だけ除外します。リンクとラーメン選択は見ません
    • 金が取れるスキルは、対応する白も除外します
    • 有効スキルデータの更新は npm run extract:effects です
