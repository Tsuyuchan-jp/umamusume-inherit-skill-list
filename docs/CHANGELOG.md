# 変更履歴

セマンティック バージョニング（MAJOR.MINOR.PATCH）です。新しいものから並べています。

- MAJOR … 使い方が変わる、互換のない変更
- MINOR … 機能の追加
- PATCH … データの追加、不具合修正、取得元の変更

1.0.0 は GitHub Pages 初回公開（2026-08-18）時点の機能をまとめたものです。1.0.1 から 1.0.6 は、バージョン表記を入れた 2026-09-28 に、公開後の変更へさかのぼって付けています。

上げるときは `package.json` の `version`、`app/index.html` の `vX.Y.Z`、このファイルの見出しを同時に更新します。

## 1.1.0 — 2026-09-28

- スキル数を指定できるようにした（既定25、1〜99）。リストの表示とコピーは同じ件数になる
- 広い画面では見出しの右、狭い画面では「ウマ娘DBを開く」の右に置く
- 指定した数はこのブラウザに1つ残る

## 1.0.6 — 2026-09-17

- ロンシャン 2400m 芝（11203）を有効スキルの同梱に追加した
- 棚のマニフェストを、古いキャッシュが残らないように取り直すようにした

## 1.0.5 — 2026-09-12

- 有効スキルを、選んだコース・脚質の1本だけ棚から取るようにした。失敗したときは同梱を使う

## 1.0.4 — 2026-09-11

- コース一覧を棚から取るようにした。失敗したときは同梱を使う

## 1.0.3 — 2026-09-10

- カード・スキル・イベントを umamusume-data から取るようにした。失敗したときは同梱を使う
- 固定の優先サポカ一覧は読まない。対象はイベントのある採用サポカ

## 1.0.2 — 2026-08-30

- 8/24 追加の育成ウマ娘 114101、サポカ 30311 / 30312 を選べるようにした
- サポカの固定40種という表記をやめた

## 1.0.1 — 2026-08-19

- アプリ名を「不足白スキルメーカー」にした
- 共有用の画像と favicon を付けた

## 1.0.0 — 2026-08-18

GitHub Pages で初回公開。

- 場と距離、脚質から、白かつ共通の有効スキルを出す
- 育成ウマ娘とサポカで取れる分（金の購入チェーンを含む）を除き、先頭25件を表示する
- いらないスキルは行から外せる。除外はこのブラウザに、コースと脚質ごとに残る
- 「スキルリストをコピー」で、表示中のスキル名をコピーする
- 各行に獲得バ身とバ/Pt。行を開くと順位（チャンミ / リグヒ）と効果・局面
- データがあるコースだけを既定で出す。「すべてのコースを見る」で全件
- 選択中のコース・脚質の U-tools 有効スキルを開く
- 使い方ダイアログ
