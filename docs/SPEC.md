# 仕様（仮）

## 目的

任意コース・脚質の U-tools 有効スキルから、本育成で取れるスキルを除いた **白因子（共通）** を有効順に出し、先頭25件を rental-factor-fill へコピーする。

## フィルタ

U-tools 有効スキルページで **白スキル ∩ 共通スキル** をオンにした集合。

実装上の近似:

- `rarity === 1`
- 固有・進化固有 ID（1xxxxx / 4xxxxx / 90xxxx）と `skillCategory === 5` を除外
- シナリオ ID（21xxxx）を除外
- `characterCardId` がある継承固有を除外

## 除外（本育成）

- サポカ40種: トレヒント + イベント全選択肢
- 育成ウマ娘: 覚醒最大の所持スキル
- シナリオ: 自動付与のみ（リンク・ラーメン選択は見ない）
- 金が取れる場合は同一購入チェーンの白も除外

## 更新

起動時フェッチはしない。`npm run extract:courses` / `extract:effects` を手動実行。
